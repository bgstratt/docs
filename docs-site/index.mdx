## Suggested first hour

1. Run `quickstart`.
2. Follow `onboarding/first-hour`.
3. Inspect runtime behavior in `developer-experience/apps` + `tutorials/trace-a-room-session`.
4. Read `architecture/mental-model` and `architecture/crdt-model`.
5. Configure `operators/server-setup` and `operators/persistence`.

## Next for operators

After your first successful room:

- Lock down deployment posture in `operators/security-and-auth`
- Add incident playbooks from `operators/troubleshooting`
- Review upgrade safety in `operators/upgrades-and-migrations`
- Review command contracts in `api-reference/websocket-commands`
